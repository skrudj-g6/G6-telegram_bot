# legacy — старый прототип бота

Сохранён только для справки (тексты, сценарий онбординга, скриншоты). Не развивается и будет удалён после выхода v1.0.

Запуск (из этой папки): `BOT_TOKEN=<новый токен> python main.py`.
Токен берётся из окружения; прежний токен был опубликован в git и должен быть перевыпущен через @BotFather.

Известные дефекты прототипа описаны в `AUDIT.md` в корне репозитория.
